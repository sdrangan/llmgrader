# Getting Started

Start here if you are new to LLM Grader.

- [What you need](./requirements.md) -- the accounts and software required to
  start, and the ones you only need later, at deployment
- [Quickstart](./quickstart.md) -- get the example course running on your own
  laptop in about 15 minutes, with no Google Cloud setup and no deployment
- [Build your own course](./buildcourse.md) -- write one question of your own and
  grade it, going through the whole authoring loop once at small scale

After that, [Building a Course Package](../buildcourse/) is the full reference for
the XML format, rubric design, and grading tests, and
[Setting Up LLM Grader](../setup/) covers installation and configuration in
detail.
